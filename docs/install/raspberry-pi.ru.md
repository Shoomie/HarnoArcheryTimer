# Установка на Raspberry Pi (ТВ-киоск)

[English](raspberry-pi.md) · [Svenska](raspberry-pi.sv.md) · [中文](raspberry-pi.zh.md) · [हिन्दी](raspberry-pi.hi.md) · [Español](raspberry-pi.es.md) · [Français](raspberry-pi.fr.md) · [العربية](raspberry-pi.ar.md) · [বাংলা](raspberry-pi.bn.md) · [Português](raspberry-pi.pt.md) · **Русский** · [اردو](raspberry-pi.ur.md)

[Windows](windows.ru.md) · [Linux](linux.ru.md) · [Назад к README](../../README.ru.md)

Результат: Pi сразу загружается в таймер на телевизоре, без входа с клавиатуры. Ядро таймера работает как фоновая служба
и поддерживает свет и звук, даже если программа отображения перезапустится.

**Проверенная платформа:** Raspberry Pi 2 Model B, Raspberry Pi OS Lite 32-bit (Trixie), HDMI-телевизор. Другие модели Pi
должны работать, но не проверялись. Время: около 30 минут.

> Подробно о том, что настраивает установщик: [deployment.md](../deployment.md) (на английском).

## Что понадобится

- Raspberry Pi с блоком питания, карта microSD (8 ГБ или больше), кабель HDMI и телевизор или монитор
- Компьютер для подготовки карты и сетевое подключение для Pi (проще всего кабель) на время установки
- По желанию: плата ESP32 для света и сирены в порт USB, USB-клавиатура или презентационный пульт

## 1. Запишите операционную систему на карту

1. На своём компьютере установите **Raspberry Pi Imager** с <https://www.raspberrypi.com/software/>.
2. Выберите модель Pi, затем *Operating System → Raspberry Pi OS (other) → **Raspberry Pi OS Lite (32-bit)***.
3. Выберите SD-карту, нажмите *Next*, затем *Edit settings* (настройка ОС) и задайте:
   - **имя хоста** (например, `archerytimer`), а также **имя пользователя и пароль** (запомните их; этот пользователь
     станет пользователем киоска),
   - **Wi-Fi**, если не используете кабель, и часовой пояс,
   - *Services → Enable SSH*.
4. Запишите карту, вставьте её в Pi, подключите HDMI и сеть и включите питание. Подождите пару минут до завершения
   первой загрузки.

## 2. Войдите

С вашего компьютера (в Windows 10/11 и Linux есть `ssh`):

```bash
ssh <username>@archerytimer.local
```

(Если имя не находится, используйте IP-адрес Pi из настроек роутера.) Можно также подключить клавиатуру к Pi и войти
на телевизоре.

## 3. Скачайте проект

```bash
sudo apt update
sudo apt install -y git
git clone <repository-url> ~/ArcheryTimer
cd ~/ArcheryTimer
```

## 4. Запустите установщик

```bash
sudo bash scripts/install_pi.sh
```

Это занимает несколько минут. Установщик ставит нужные пакеты, копирует программу в `/opt/archerytimer`, настраивает
фоновую службу, включает GPU-слой отображения и делает так, чтобы Pi сам входил на первой консоли и запускал там
таймер. Когда он закончит, перезагрузите Pi:

```bash
sudo reboot
```

После перезагрузки таймер появится на телевизоре сам. Используйте мышь или клавиатуру (Пробел = большая кнопка,
Esc = аварийная остановка).

Параметры: `--no-ui` для блока только со светом и звуком без экрана, `--user NAME` — выбрать пользователя киоска.
Список — по команде `scripts/install_pi.sh --help`.

## 5. Подключите свет и сирену (по желанию)

Подключите плату ESP32 к порту USB на Pi. Она находится автоматически (пользователь киоска уже в группе `dialout`).
Состояние показано в меню оборудования программы. Чтобы прошить новую плату, см.
[руководство по прошивке](../flashing.md) (на английском); исходники прошивки лежат в [`firmware/`](../../firmware/).

## Настройки

Дополнительные параметры запуска хранятся в двух небольших файлах. Редактируйте их через `sudo nano`:

| Файл | Для чего | Пример |
| --- | --- | --- |
| `/etc/archerytimer/core.env` | фоновое ядро | `CORE_ARGS="--no-audio"` |
| `/etc/archerytimer/ui.env` | экран | `UI_ARGS="--lang sv --profile audience"` |

Применение: `sudo systemctl restart archerytimer-core`, а для экрана — перезагрузка (или выход из консоли). Как
объединить несколько Pi (один ведущий, остальные ведомые), см. [cluster.md](../cluster.md) (на английском).

## Обновление

```bash
cd ~/ArcheryTimer && git pull && sudo bash scripts/install_pi.sh && sudo reboot
```

Ваши настройки и файлы в `/etc/archerytimer` сохраняются.

**С компьютера Windows**, если на Pi нет git: `.\scripts\deploy_to_pi.ps1 -Pi username@archerytimer.local`
(копирует проект и запускает установщик; добавьте `-Reboot`, чтобы потом перезагрузить Pi).

## Как получить обычную консоль на телевизоре

Киоск занимает первую консоль Pi. Чтобы работать на самом Pi, войдите по **SSH** с другого компьютера или создайте файл
`~/.no-kiosk` (`touch ~/.no-kiosk`) и перезагрузитесь — появится обычное приглашение. Удалите файл и перезагрузитесь,
чтобы вернуть таймер.

## Если что-то не работает

| Проблема | Что делать |
| --- | --- |
| Чёрный экран после перезагрузки | Подождите 1–2 минуты после включения. Проверьте HDMI. Если не проходит, войдите по SSH, выполните `journalctl -u archerytimer-core -n 50` и посмотрите `~/.local/share/archerytimer/logs/ui.log` |
| Экран чёрный, только если телевизор включён позже Pi | Добавьте `hdmi_force_hotplug=1` в `/boot/firmware/config.txt` и перезагрузитесь |
| Экран работает, но «нет связи с ядром» | `systemctl status archerytimer-core`; перезапустите: `sudo systemctl restart archerytimer-core` |
| Нет света/сирены | Проверьте, что USB-кабель передаёт данные; `ls /dev/ttyACM* /dev/ttyUSB*` должен показать устройство |
| Проверить окружение | `/opt/archerytimer/.venv/bin/python /opt/archerytimer/scripts/env_probe.py` |
| Удалить всё | `sudo bash scripts/uninstall_pi.sh` (настройки сохраняются) |

Журнал в реальном времени: `journalctl -u archerytimer-core -f`. Подробности устройства: [deployment.md](../deployment.md) (на английском).
