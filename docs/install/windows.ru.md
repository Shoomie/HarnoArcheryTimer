Время: около 10 минут. Интернет нужен только при первой установке.

## 1. Установите Python

1. Откройте <https://www.python.org/downloads/> и скачайте последнюю версию Python 3 (3.9 или новее).
2. Запустите установщик. **Отметьте «Add python.exe to PATH»** на первом экране, затем нажмите *Install Now*.

## 2. Скачайте проект

Выберите один способ:

- **ZIP (проще всего):** на странице GitHub нажмите **Code → Download ZIP**, затем щёлкните файл правой кнопкой и
  выберите *Извлечь всё*. Положите папку в простое место, например `C:\ArcheryTimer`.
- **Git:** `git clone <repository-url> C:\ArcheryTimer`

## 3. Настройка (один раз)

Откройте папку проекта и **дважды щёлкните `scripts\setup_windows.bat`**. Скрипт создаёт отдельную среду Python в
`.venv` и устанавливает всё необходимое для таймера. Дождитесь надписи «Done».

Если Windows SmartScreen предупреждает о файле, выберите *Подробнее → Выполнить в любом случае* (это обычный текстовый
скрипт, его можно прочитать в Блокноте).

## 4. Запустите таймер

Дважды щёлкните **`scripts\start_windows.bat`**. Откроется окно с таймером.

- Оборудования для света пока нет? Запустите из терминала `scripts\start_windows.bat --no-serial` для демонстрации.
- Полный экран на телевизоре: `scripts\start_windows.bat -- --fullscreen`
- Шведский интерфейс: `scripts\start_windows.bat -- --lang sv` (язык можно сменить и в меню настроек)
- Второй монитор для зрителей, без кнопок управления: `scripts\start_windows.bat -- --profile audience --display 1`

(Чтобы создать ярлык на рабочем столе: щёлкните `start_windows.bat` правой кнопкой → *Отправить → Рабочий стол (создать ярлык)*.)

Клавиши: **Пробел** = большая кнопка, **P** = пауза, **Esc** = аварийная остановка. См.
[README](../../README.ru.md).

## 5. Подключите свет и сирену (по желанию)

Подключите плату ESP32 к порту USB. Программа найдёт её сама. Если нет:

1. Откройте *Диспетчер устройств → Порты (COM и LPT)* и запишите порт, например `COM7`.
2. Запустите с параметром: `scripts\start_windows.bat --serial-port COM7`.

Некоторым дешёвым платам нужен драйвер USB-serial (CH340 или CP210x); если COM-порт не появляется, установите драйвер
от производителя чипа. Прошивка платы лежит в [`firmware/`](../../firmware/); новую плату прошивают по
[руководству по прошивке](../flashing.md) (на английском).

## Обновление

Скачайте новый ZIP (или выполните `git pull`) и снова запустите `scripts\setup_windows.bat`. Ваши настройки хранятся в
профиле пользователя (`%LOCALAPPDATA%\archerytimer`), а не в папке проекта.

## Если что-то не работает

| Проблема | Что делать |
| --- | --- |
| «Python was not found» | Переустановите Python, отметив *Add python.exe to PATH*, или повторите настройку после перезагрузки ПК |
| Окно открывается и сразу закрывается | Запустите `scripts\start_windows.bat` из терминала (`cmd`), чтобы увидеть сообщение об ошибке |
| В состоянии оборудования «нет света» | Проверьте USB-кабель (он должен передавать данные), порт и драйвер; см. шаг 5 |
| Журналы | `%LOCALAPPDATA%\archerytimer\logs` (вставьте путь в адресную строку Проводника) |
