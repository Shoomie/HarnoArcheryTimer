# Archery Timer (таймер для стрельбы из лука)

[English](README.md) · [Svenska](README.sv.md) · [中文](README.zh.md) · [हिन्दी](README.hi.md) · [Español](README.es.md) · [Français](README.fr.md) · [العربية](README.ar.md) · [বাংলা](README.bn.md) · [Português](README.pt.md) · **Русский** · [اردو](README.ur.md)

Таймер для стрельбы из лука с открытым исходным кодом. Он ведёт время стрельбы на соревнованиях и тренировках, показывает
его на телевизоре или мониторе и управляет светофорами и сиреной по USB. Создан для небольшого клуба стрельбы из лука и
рассчитан на волонтёров без технической подготовки: на экране одна очевидная кнопка для следующего действия и всегда
видимая кнопка аварийной остановки.

- Работает на **Windows 10/11**, **Linux**, **Raspberry Pi** (2B и новее, как ТВ-киоск) и macOS.
- Интерфейс на английском (по умолчанию) и шведском языках.
- Таймер, свет и звук продолжают работать, даже если программа отображения зависла.
- Дополнительно: плата ESP32 для света и сирены, вторые экраны и несколько устройств в одной сети.

> **Перед официальными соревнованиями:** значения времени в `config/` — **временные заготовки**, а не подтверждённые
> правила World Archery / SBF. Сверьте их с действующими правилами и отредактируйте файлы TOML (клубы могут добавлять
> собственные пресеты без изменения кода). Система проверена от начала до конца на ПК с Windows, ПК с Linux и
> Raspberry Pi 2B с модулями ESP32-C3 и WROOM-32D. Пока не проверено: 4-часовой непрерывный прогон, платы ESP32-S3 и
> радиотесты на большом расстоянии.

## Как провести занятие

1. Запустите программу (см. «Установка» ниже). Нажмите **Пробел** или большую кнопку: откроется настройка.
2. Выберите карточку (например, *Indoor 18 m*), линии и число серий, затем начните.
3. Большая кнопка всегда подсказывает, что будет дальше: начать серию, следующая серия, продолжить. **P** — пауза.
   **Esc** — аварийная остановка: красный свет и тишина, всегда одним нажатием, без подтверждения.

На экране — большой сигнал (с символом, а не только цветом), обратный отсчёт, серия и линия, а также состояние
оборудования простыми словами.

## Установка

Выберите свою систему. Каждое руководство ведёт по шагам от нуля до работающего таймера.

| Система | Руководство | Кратко |
| --- | --- | --- |
| **Windows 10/11** | [docs/install/windows.ru.md](docs/install/windows.ru.md) | Установить Python, скачать проект, дважды щёлкнуть `scripts\setup_windows.bat`, затем `scripts\start_windows.bat` |
| **Linux** (и macOS) | [docs/install/linux.ru.md](docs/install/linux.ru.md) | `scripts/setup_desktop.sh`, затем `scripts/start.sh` |
| **Raspberry Pi** (ТВ-киоск) | [docs/install/raspberry-pi.ru.md](docs/install/raspberry-pi.ru.md) | Записать Pi OS Lite, `git clone`, `sudo scripts/install_pi.sh`, перезагрузить |

### Быстрый старт (любой компьютер, без оборудования)

1. Установите **Python 3.9 или новее** ([python.org](https://www.python.org/downloads/); в Linux обычно
   `sudo apt install python3 python3-venv python3-pip`).
2. Скачайте проект: на GitHub нажмите **Code → Download ZIP** и распакуйте архив, либо
   `git clone <repository-url>`.
3. В папке проекта один раз запустите скрипт установки, затем скрипт запуска:

   | | Установка (один раз) | Запуск |
   | --- | --- | --- |
   | Windows | `scripts\setup_windows.bat` | `scripts\start_windows.bat --no-serial` |
   | Linux / macOS | `scripts/setup_desktop.sh` | `scripts/start.sh --no-serial` |

   `--no-serial` означает «оборудование света не подключено». Уберите его, когда плата ESP32 подключена; программа
   найдёт её сама.

### Управление

| Клавиша | Действие |
| --- | --- |
| **Пробел** / Enter | Большая кнопка: то, что идёт дальше (открыть настройку, начать серию, ...) |
| **P** | Пауза / продолжить |
| **Esc** | **Аварийная остановка**: красный свет и тишина, всегда одним нажатием |
| S | Остановить серию |
| N / Backspace | Следующая фаза / назад (в течение 5 секунд после «Стоп» или «Далее» кнопка «Назад» называется *Отмена*) |
| M / F1 | Меню: новая сессия, таймеры, настройки, состояние оборудования, сеть, звук, выход |

Всё работает и мышью. Презентационные пульты и педали, которые работают как клавиатура, тоже подходят, как и кнопки
модулей ESP32. Полный список: [docs/ui.md](docs/ui.md) (на английском).

### Полезные параметры запуска

Добавляйте их после скрипта запуска, параметры экрана — после `--`:

```text
scripts/start.sh --no-serial                      демо без оборудования
scripts/start.sh --serial-port COM7               выбрать USB-порт самостоятельно (Linux: /dev/ttyACM0)
scripts/start.sh -- --fullscreen --lang sv        полный экран, интерфейс на шведском
scripts/start.sh -- --profile audience --display 1   экран для зрителей на втором мониторе, без кнопок управления
```

В Windows используйте `scripts\start_windows.bat` вместо `scripts/start.sh`.

## Структура репозитория

```text
src/archerytimer/   сама программа (служба-ядро, клиент интерфейса, оборудование, аудио, IPC)
config/             последовательности времени и пресеты (TOML, временные)
locales/            все тексты интерфейса, en.toml и sv.toml
assets/             шрифт (Inter, OFL)
firmware/           прошивка ESP32 (PlatformIO), готовые образы, общие тестовые векторы
scripts/            скрипты установки/запуска, установщик для Raspberry Pi, меню прошивки, замеры производительности
docs/               документация
tests/  tools/      набор тестов, симулятор ячеистой сети
```
