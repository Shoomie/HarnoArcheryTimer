# Arbiter scenarios (docs/mesh.md section 4). Shared by the C++ arbiter (firmware/lib/meshcore) and the
# Python simulator. Time is in ms from 0; events are applied in file order and an expect sees only the events above it.
#
#   scenario <name>
#   config role=<M|F|E|N> host=<alive|dead> [master_id=<8 hex>]       (host alive/dead from t=0)
#   at <ms> [every <ms> until <ms>] rx TIMER master=<8 hex> rank=<0-2> lights=<letters|O> [flags=<n>] [session=<n>, default 1]
#                                    [sound_seq=<n> sound_count=<n> sound_age=<ms>]
#   at <ms> [every ... until ...] rx SOUND master=<8 hex> seq=<n> count=<n>
#   at <ms> host alive|dead   at <ms> host lights=<letters|O>   at <ms> reboot (RAM state lost, persisted sessions kept)
#   at <ms> expect key=value ...      keys: follow=<8 hex|none> lights=<letters in G,Y,R order|O>
#                                     sound_started=<cumulative patterns started> sound_active=<0|1> conflict=<0|1>
#                                     failsafe=<0|1> tx_rank=<0|1|2>   (omitted keys are not checked)
#
# Definitions used by every implementation:
#  - live master: last TIMER heard less than 1000 ms ago. failsafe=1 (lights R, silent) iff the node is not
#    host-driven and has no live followed master, or the host is dead (role M/F), or role N/E and nobody live.
#  - switch: the followed master has been silent >= 600 ms and another is live, or a live master of higher
#    rank has been heard for >= 400 ms (first frame to now). Ties: highest rank, then lowest master_id.
#  - conflict=1 iff at least two distinct master_ids of rank 2 are "active": the second most recent frame of
#    each is no older than 600 ms. A role-M node with a live host counts as one active rank-2 master.
#  - A newly followed master's first TIMER only records its sound_seq. A sound starts from a TIMER only if
#    its sound_seq differs from the recorded one and sound_age < 400. SOUND frames start when seq differs.
#  - Emergency flag (flags bit1) forces lights R while set. A SOUND/TIMER with count 0 and a new sound_seq stops a
#    running pattern at once, whatever its sound_age. sound_active=1 while a pattern runs (blast or gap).
#  - Session rule (mesh.md section 4): per master_id the highest accepted session is persisted (survives reboot);
#    a TIMER/SOUND with a lower session is dropped completely (it neither drives outputs nor counts as heard).

scenario stickiness_and_conflict
config role=N host=dead
at 0 every 200 until 1000 rx TIMER master=00000001 rank=2 lights=G
at 250 every 200 until 1050 rx TIMER master=00000002 rank=2 lights=R
at 0 expect follow=00000001 lights=G failsafe=0 conflict=0
at 250 expect follow=00000001 lights=G conflict=0
at 450 expect follow=00000001 lights=G conflict=1
at 1050 expect follow=00000001 lights=G conflict=1

scenario failsafe_and_recover
config role=N host=dead
at 0 expect follow=none lights=R failsafe=1
at 0 every 200 until 1000 rx TIMER master=00000001 rank=2 lights=G
at 1000 expect lights=G failsafe=0
at 1999 expect lights=G failsafe=0
at 2000 expect lights=R failsafe=1
at 2100 rx TIMER master=00000001 rank=2 lights=G
at 2100 expect lights=G failsafe=0
