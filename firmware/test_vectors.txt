# Serial protocol v1 test vectors, shared by the Python tests and the firmware tests.
#
# Format, one vector per line (blank lines and '#' comments are ignored):
#   <frame> => OK <CMD> [<arg> ...]    decodes; the fields are the command and its arguments
#   <frame> => ERR <code>              rejected; code is CS, UC, BA, OV or MF
# An argument that is empty is written as '-'. Frames are given without the trailing newline.
# For OK vectors, re-encoding the parsed fields must reproduce the frame byte for byte.
# Checks run in this order: length (OV), framing (MF), checksum (CS), command (UC), args (BA).
# Generated with an XOR written independently of protocol.py; $L,G*27 was also checked by hand.
